# Claude Code Basics

Using the AI coding assistant.

---

## What is Claude Code?

Claude Code is an AI assistant that can help you with:
- Answering questions about the codebase
- Writing commit messages
- Fixing errors
- Making complex edits

---

## When to Use It

- "How do I add a new project?"
- "Why isn't my image showing up?"
- "Create a commit for my changes"
- "Help me fix this error"

---

## Limitations

- Can't access external websites
- Works best with clear, specific questions
- Always review suggested changes before applying
