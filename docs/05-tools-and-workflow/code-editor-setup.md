# Code Editor Setup

Installing and using VS Code for editing site files.

---

## What is a Code Editor?

A code editor is a specialized text editor for working with code and markdown files. We recommend **Visual Studio Code** (VS Code) because it's:
- Free and open-source
- Beginner-friendly
- Cross-platform (Mac, Windows, Linux)
- Has great markdown support

---

## Step 1: Download VS Code

Visit: https://code.visualstudio.com/

Click the download button for your operating system.

---

## Step 2: Install

- **Mac:** Open the downloaded .dmg file, drag VS Code to Applications
- **Windows:** Run the .exe installer
- **Linux:** Follow instructions for your distribution

---

## Step 3: Open the Project

1. Launch VS Code
2. File → Open Folder
3. Navigate to your lowdo-dot-net folder
4. Click "Open"

---

## Step 4: Navigate Files

Use the sidebar to browse files:
- Click folders to expand them
- Click files to open them
- Use Cmd+P (Mac) or Ctrl+P (Windows) to quickly find files

---

## Recommended Extensions

Install these extensions for a better experience:

1. **Markdown All in One** - Preview markdown files
2. **YAML** - Syntax highlighting for frontmatter

To install: Click Extensions icon (sidebar) → Search → Install

---

## Tips

- **Save:** Cmd+S (Mac) or Ctrl+S (Windows)
- **Search:** Cmd+F (Mac) or Ctrl+F (Windows)
- **Open terminal:** View → Terminal
