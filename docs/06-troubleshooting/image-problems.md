# Image Problems

Troubleshooting image issues.

---

## "Image doesn't appear"

**Check:**
1. Filename has no spaces (use hyphens)
2. Lowercase letters only
3. Correct extension (.jpg, .png)
4. File is in same folder as .md file

**Fix:**
- Rename file: `my-image.jpg`
- Move to correct folder
- Check file isn't corrupted

---

## "Wrong image shows up"

**Check:**
1. Multiple `header.*` or `thumb.*` files?
2. Is desired image named correctly?

**Fix:**
- Delete duplicate thumbnails
- Rename main image to `header.jpg`

---

## "Image looks blurry"

**Fix:**
- Upload higher resolution (1200px+ wide)
- Check original image quality
