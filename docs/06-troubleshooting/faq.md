# Frequently Asked Questions

---

## Content Questions

**Q: Can I use spaces in file/folder names?**
A: No, use hyphens instead. `my-project` not `my project`

**Q: Do I need to know HTML/CSS?**
A: No! Just write markdown and fill in frontmatter.

**Q: How long until changes appear live?**
A: 3-5 minutes after pushing to GitHub.

**Q: Can I preview before publishing?**
A: Yes, use pull request previews on Netlify.

---

## Technical Questions

**Q: What if I accidentally delete something?**
A: Git saves all history. You can recover it.

**Q: Can multiple people work at once?**
A: Yes! Use branches to work independently.

**Q: Where do I get help?**
A: Check this documentation, then ask a team member.
