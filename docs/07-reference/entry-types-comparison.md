# Entry Types Comparison

Quick reference for all entry types.

---

## Entry Types Table

| Type | Folder | Gets Page? | Use For |
|------|--------|-----------|---------|
| Project | `entries/projects/` | ✅ Yes | Design and architecture work |
| News | `entries/news/` | ❌ Index only | Studio announcements |
| Award | `entries/awards/` | ❌ Index only | Honors and recognitions |
| Feature | `entries/features/` | ❌ Index only | Press coverage |
| Lecture | `entries/lectures/` | ❌ Index only | Talks and presentations |
| Exhibition | `entries/exhibitions/` | ❌ Index only | Gallery shows |
| Staff | `entries/staff/` | ❌ Index only | Team updates |

---

## Key Differences

**Projects:**
- Get individual pages
- Have image galleries
- Include collaborators
- More detailed content

**Updates:**
- Index only
- Single thumbnail
- Can link externally
- Brief descriptions
