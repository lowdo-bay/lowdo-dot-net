# File Naming Conventions

Naming rules and best practices.

---

## Folders

- **Lowercase only:** `casa-marianella`
- **Hyphens for spaces:** `wolf-creek-ranch`
- **Descriptive:** `community-housing-center`
- **No special characters:** Avoid `_`, `#`, `@`, etc.

✅ Good: `casa-marianella`, `ut-lecture-2024`
❌ Bad: `Casa_Marianella`, `project#1`

---

## Markdown Files

Must match folder name exactly:

✅ `casa-marianella/casa-marianella.md`
❌ `casa-marianella/project.md`

---

## Images

- **Lowercase:** `header.jpg`
- **Hyphens:** `01-exterior-view.jpg`
- **Descriptive:** `detail-closeup.jpg`

Special names:
- `header.jpg` / `header.png` - Thumbnail
- `thumb.jpg` / `thumb.png` - Alternative thumbnail

---

## Categories

- **ALL CAPS:** `HOUSING`, `SUSTAINABLE`
- **No punctuation**
- **Singular or plural** (be consistent)
