ADU LIBRARY · MOCKUPS

Five high-fidelity prototypes exploring different ways to present the free ADU design library. Each mockup uses the LowDO design system and the same shared dataset of 10 ADU designs.

For evaluation only.

Pick the direction that feels right; the winner becomes a real Eleventy template.

CONCEPT
A
Configurator Wizard

A four-step quiz (budget · bedrooms · orientation · preferences) that ranks the best matching designs. Best for first-time visitors who want to be told what to look at.

 B
Filterable Catalog

All designs as rows in a spreadsheet-style table on the standard 4-col grid. Sticky filters, expandable rows, in-line download gate. The most on-brand option.

 C
Compare Tray

Catalog + a fixed-bottom tray that holds up to 3 designs. Click compare to see them side-by-side as a true spreadsheet, with winning attributes highlighted.

 D
Tiered Showcase

Pricing-page style with three tiers (Essential / Standard / Plus). Story-driven, less browsing, more guided narrative. Each tier features 2–3 designs.

 E
Spectrum Canvas

All designs plotted on a 2D field (budget × complexity). Hover for previews, click for details. The most experimental — treats the catalog as one legible diagram.

 ·
Plan Document

The written plan that describes goals, the shared content model, CSS reuse, and what each mockup is meant to demonstrate.
